# local 測試環境設定（WSL2，直跑 binary，不在容器）

## 連線資訊

| 項目            | 值                          |
| --------------- | --------------------------- |
| URL             | `http://localhost:8081`     |
| Port            | `8081`                      |
| 容器            | 無（直跑 binary）            |
| Log             | `/tmp/perch.log`            |

## 啟動方式

```bash
# 1. 編譯
cd /home/dorowu/workspace/mykb/code/perch
go build -o perch .

# 2. 啟動（log 存到 /tmp/perch.log）
LISTEN_ADDR=:8081 \
CLAUDE_WORKDIR=/home/dorowu/workspace \
DB_PATH=/tmp/perch.db \
./perch > /tmp/perch.log 2>&1 &

# 3. 確認
curl -s http://localhost:8081/ | head -5
tail -f /tmp/perch.log
```

## 環境變數

| 環境變數          | 本地預設值                      | 說明                                     |
| ----------------- | ------------------------------- | ---------------------------------------- |
| `LISTEN_ADDR`     | `:8081`                         | 避開 8080（可能被其他服務佔用）            |
| `CLAUDE_WORKDIR`  | `/home/dorowu/workspace`        | Claude Code 的工作目錄                   |
| `DB_PATH`         | `/tmp/perch.db`                 | SQLite，避免寫到 `/data`（本機沒有此路徑）|
| `PERCH_MODE`      | `single`（預設）                | 單使用者模式                             |
| `AUTH_METHOD`     | `none`（預設）                  | 本地開發不需要認證                        |
| `ADMIN_TOKEN`     | 不設定（預設）                  | 不設定則 admin 路由全開放                 |

> `ADMIN_TOKEN` 不設定時，Settings UI 和 `/admin/*` 路由對所有人開放，本地開發方便。

## 停止

```bash
# 找到 perch process 並 kill
lsof -ti tcp:8081 | xargs kill -9
# 或
pkill -f './perch'
```

## 注意事項

| 項目               | 說明                                                                     |
| ------------------ | ------------------------------------------------------------------------ |
| `/data` 不存在     | 本機沒有 `/data` 目錄，務必設 `DB_PATH=/tmp/perch.db`                   |
| frontend 需先 build | 若改了前端，先執行 `cd frontend && npm run build` 再重新編譯 Go binary    |
| port 8080 衝突     | WSL2 上 8080 可能被其他服務佔用，預設改用 8081                           |

## Agent 操作規範

- 本環境直跑 binary，**不使用 docker**
- 改了 Go 程式碼需重新 `go build`，改了前端需重新 `npm run build`
- 測試截圖可存 `/tmp/`
